--- title: "OxidOWL" excerpt: "OxidOWL is a DL reasoner for OWL ontologies.
" collection: portfolio --- OxidOWL is a description logic (DL) reasoner for OWL ontologies. It allows for efficient reasoning over ontologies, enabling tasks such as consistency checking, classification, and query answering. OxidOWL supports various OWL profiles and can be used in a variety of applications, including semantic web services, knowledge management systems, and artificial intelligence. OxidOWL is developed in Rust, which provides performance benefits and memory safety. It is available as an open-source project on GitHub, where you can find the source code, documentation, and examples of how to use it in your projects. The reasoner was created as part of a project on the development and maintenance of software using coding agents. Manual and documentation are available in the GitHub repository.
