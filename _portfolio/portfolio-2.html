" collection: portfolio --- SMOL is a programming language and runtime environment for semantic lifting. Semantic lifting is a technique that allows programs to interpret their own states as knowledge graphs and enrich them with ontological knowledge. This enables programs to query their own knowledge graph and use domain knowledge expressed in OWL ontologies directly at runtime to guide their execution. Manual and documentation are available in the github repository.
